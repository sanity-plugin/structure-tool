# @structure-tool/tsdown-config

Shared TSDown configuration for the monorepo.

## Usage

### Base Configuration

```js
// tsdown.config.ts
import config from '@structure-tool/tsdown-config/base';

export default config;
```

### Package Configuration

```js
// tsdown.config.ts
import config from '@structure-tool/tsdown-config/package';

export default config;
```
